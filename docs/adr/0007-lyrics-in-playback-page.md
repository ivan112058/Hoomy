# 0007 - 歌词在播放页内同层切换，不设独立页面

日期：2026-09-10　状态：已接受

## 背景

歌词三档的呈现方式（见 ADR-0004）需要确定界面形态。参考项目 SmartisanMusic-Revived 的做法是：歌词与封面在播放页内**同层切换**（点封面或点歌词互切，带淡入缩放动画），并在歌词态显示「屏幕常亮」按钮。备选是独立歌词页，或播放页下方常驻一小块歌词。

## 决策

歌词与封面在播放页内**同层切换**：

1. 点击静止封面切到歌词，点击歌词切回封面。
2. 歌词态提供「屏幕常亮」开关，离开歌词态或页面时清除。
3. 不设独立歌词页。

## 后果

- 与「播放页静止封面」（ADR-0003）互补：静止封面因此获得一个交互用途。
- 切换不额外发起请求，歌词在进入播放页时随曲目预取。
- 常驻小块歌词的形态被放弃；用户要读歌词须切到全屏歌词态，阅读面积更大，符合「歌词是阅读内容」的定位。
